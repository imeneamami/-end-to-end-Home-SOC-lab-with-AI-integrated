# End-to-end-Home-SOC-lab-with-AI-integrated
cyber home lab project , we used tools such as wazuh, grafana, netalertx and AIRIA AI built on a powerful central server called Zima Cube.
We will setup wazuh manager and wazuh agent and perform file and integrity monitoring. We will also setup netalertx in a docker container and view all devices on our home network. Grafana will then be setup to view these metrics from wazuh and netalertx in a central dashbaord and finally we will setup and run an AI agent to perform alert summarisation in our Home SOC
